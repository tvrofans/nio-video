# NIO Video 🚘🎬

一个专为车载浏览器（特别是蔚来 NIO Banyan/Aspen 系统）打造的轻量化、极速影视聚合 Web 应用。基于 Python Flask 编写，采用 Docker 一键极速部署。

由 **LiMuZi** 开发与维护。

## ✨ 核心“杀手锏”：突破行车限制

默认情况下，蔚来系统出于安全策略，在车辆行驶（挂入 D 挡）时会强制屏蔽视频画面，仅保留声音。
**本项目通过特定的 Web 播放容器与前端解码策略（DPlayer + HLS.js），完美绕过了车机底层的视频播放检测机制。** 只需通过车机浏览器打开本项目，即可实现**行驶过程中画面正常播放、绝不黑屏**，让副驾及后排乘客在漫长旅途中享受沉浸式观影体验！

*(⚠️ 安全提示：行车播放功能仅供副驾及后排乘客娱乐使用，请驾驶员在行车过程中严格遵守交通法规，切勿注视屏幕！)*

## 🚀 其他核心特性

* **🚘 车机完美适配**：彻底摒弃影响车机性能的庞大外部框架，全站采用纯原生 CSS 编写，利用 `padding-top` 经典方案强制撑开播放器比例，彻底杜绝车机浏览器“彻底白屏”、“卡死”现象。
* **🔄 多源智能兜底**：告别“死链”和“暂无内容”。采用“多源自动轮询”与“片名全网智搜”逻辑。若当前播放源失效或网络波动，后端与前端会双重接管，自动无缝切换至备用可用源（支持红牛、速播、光速、海外等）。
* **⚡️ 极速加载体验**：首页画廊采用异步并发请求，海报强制 2:3 黄金比例自动裁剪对齐；将重型视频脚本后置加载，确保车机界面瞬间呈现。
* **🐳 Docker 一键部署**：无需繁琐的 Python 环境配置，一条命令即可启动或更新服务。

## 🛠️ 部署与安装方式

本项目推荐使用 **Docker** 和 **Docker Compose** 进行部署，对宿主机环境零污染。

### 1. 环境准备
确保您的服务器（VPS）已安装 Docker 和 Docker Compose。
如果尚未安装，可执行以下命令快速安装（以 Ubuntu/Debian 为例）：
```bash
sudo apt update
sudo apt install docker.io docker-compose -y
```

### 2. 克隆项目
将代码拉取到您的服务器中：
```bash
git clone [https://github.com/tvrofans/nio-video.git](https://github.com/tvrofans/nio-video.git)
cd nio-video
```

### 3. 配置数据源 (可选)
项目自带默认的影视接口配置。如需增删修改，请编辑项目根目录下的 `db.json` 文件。支持所有标准的苹果 CMS (MacCMS) API 采集接口。
```json
{
    "key": "hongniu",
    "name": "红牛资源",
    "api": "[https://www.hongniuzy2.com/api.php/provide/vod/](https://www.hongniuzy2.com/api.php/provide/vod/)",
    "active": true
}
```

### 4. 一键启动
在项目根目录下，执行以下命令构建并启动容器：
```bash
docker-compose up -d --build
```
服务启动后，默认映射在宿主机的 `5000` 端口。
车机浏览器访问 `http://您的服务器IP:5000` 或绑定的域名，即可开始使用。

## 💡 车机端使用注意事项

1.  **缓存清理**：若您更新了服务器代码，请务必在车机浏览器的“设置”中**清除一次缓存**，以防止加载旧版本的静态文件导致报错。
2.  **网络要求**：车机行驶中网络可能出现波动，如果播放过程中遇到某一部影片一直转圈缓冲，只需点击播放器下方的其他【资源站线路】按钮，即可无缝原地切换片源。
